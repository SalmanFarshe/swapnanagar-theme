# Swapnanagar – Community WordPress Theme

Swapnanagar is a custom-built **WordPress theme** designed for community living. It allows members to connect, view flats, post to-let listings, exchange products, offer tutoring, share books, and stay updated with community news.

## ✅ Features
- **User Roles:** Guest, Member, Owner, Admin
- **Flats Directory:** View all buildings & flats
- **To-Let Listings:** Add and manage rental information
- **Owner Verification:** Request and approve ownership
- **Community Marketplace:** Buy, sell, or donate items
- **Tutoring & Book Sharing:** Connect through educational resources
- **Community News:** Announcements and blog updates
- **Contact & Support:** Easy communication with admin and members

## 🛠 Tech Stack
- **WordPress 6.x**
- **Bootstrap 5** for responsive design
- **Custom Plugins** for membership, flats management, marketplace, and more
